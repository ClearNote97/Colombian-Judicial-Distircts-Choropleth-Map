# `data/other/` — datos en formatos no-SQL

Aquí viven los **archivos de datos de entrada** en los distintos formatos que **no son SQL**:
`.csv`, `.parquet`, `.xlsx`, `.json`, `.txt`, etc.

- Es el **insumo** del análisis (el resultado va a `output/`).
- Datos **sensibles o pesados**: no versionar — ajusta el `.gitignore` según lo exija el proyecto.
